# iso-20022

Strongly typed ISO 20022 (MX) messages for Rust, generated from the official
XML Schemas.

> **Status: pre-release.** Only `MessageIdentifier` is implemented; no message
> types have been generated yet. Nothing is published to crates.io.

## Scope

- One Rust module per message version (for example `pacs.008.001.08`),
  generated by [`iso-20022-codegen`](../iso-20022-codegen) from the official
  XSD.
- XML serialization and deserialization with `serde` and `quick-xml`.
- Only the message versions users ask for are generated. The first set:
  `pain.001`, `pain.002`, `pacs.008`, `pacs.002`, `pacs.004`, `camt.053`,
  `camt.054`, `camt.056`, at the versions the first adopters need.

## Correct by construction

A value of a generated type is a value the schema accepts:

- **Code lists are enums.** `ChargeBearerType1Code` cannot hold a code
  that is not in the list.
- **Facets are validated newtypes.** `Max35Text`, `ActiveCurrencyAndAmount`
  or `IBAN2007Identifier` can only be built through a constructor that checks the
  length, pattern, digits or range.
- **Cardinalities are typed containers.** `1..1` is a plain field, `0..1` an
  `Option`, `1..n` a non-empty collection, bounded `n..m` a collection that
  checks its bounds.

What types cannot express (cross-element rules from the MDR, scheme usage
guidelines) is checked by explicit validation, not left to the caller.

## Testing

Every generated message round-trips through XML, is checked against an
independent XSD validator, and is tested against the example instances
published with the Message Definition Reports. See the
[verification ladder](../../README.md#how-we-verify).

## Where the XSDs come from

Schemas are published in the
[ISO 20022 message catalogue](https://www.iso20022.org/iso-20022-message-definitions).
They are downloaded by the user, or by the codegen tool, at generation time.
They are **never committed** to this repository, except as test fixtures,
and each fixture records the URL it was downloaded from.

## Example

```rust
use iso_20022::MessageIdentifier;

let id = MessageIdentifier::parse("pacs.008.001.08")?;
assert_eq!(id.business_area(), "pacs");
assert_eq!(id.version(), 8);
```
